03 · State def

StationStates

Estados de operación de controller.operatingStates

available → processingPackageDetected
processing → availableCycleConfirmed
processing → blockedCycleFailed
blocked → availableResetRequested y ambos valores libres → recordAcceptedReset
blocked → blockedResetRequested y algún sensor ocupado → recordRejectedReset
Entradas: entrySensorClear : Boolean y exitSensorsClear : Boolean.
Entrada lógica → available; la secuencia física de arranque sigue pendiente.
Rearme mediante nueva pulsación.El operador inspecciona y despeja. El rearme aceptado conserva el fallo y no inicia movimiento. Fuera de blocked se ignora; un botón mantenido o una solicitud rechazada no generan rearme automático.

Lectura del modelo

Qué está definido y qué falta

Vista manual basada en el SysML y el HTML existentes. No es un compilador ni una simulación ejecutable.

  1. Las flechas continuas de componentes y ciclo representan las conexiones y secuencias descritas en los archivos fuente.
  2. El panel de estados representa el comportamiento previsto; no certifica la interpretación del modelo por un motor SysML.
  3. Integración pendiente Vincular explícitamente la ejecución de PackageCycle con processing y la emisión de CycleConfirmed / CycleFailed.
  4. Integración pendiente Conectar las lecturas actuales de los sensores con las condiciones de rearme y definir el arranque.
